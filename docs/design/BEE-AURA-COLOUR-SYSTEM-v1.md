# Bee-Aura Colour System v1.0 — Approved Direction

Bee-Aura AI / Lead Recovery OS stays dark.

Approved direction:

Dark premium AI operating system — not a plain CRM, not a neon AI toy, not a cartoon bee app.

## Core rule

Bee-Aura uses colour by meaning, not decoration.

- Gold = Bee-Aura brand, premium value, recovered revenue, key commercial moments.
- Blue = AI, system intelligence, automation, insight, diagnostics.
- Green = success, recovered, confirmed, completed.
- Amber = warning, caution, at risk, pending.
- Red = errors, failed actions, danger, destructive actions.
- Dark navy / black = professional operating system base.

Brand gold must not be used as warning yellow.

## Usage ratio

- 72% dark base
- 20% dark cards / surfaces
- 4% gold
- 2.5% blue
- 1.5% status colours

## Page rules

Error Log should be serious and controlled. Use red for errors, amber for warnings, blue for diagnostics/AI assist, and only small gold Bee-Aura brand touches.

All pages must be aligned to this system page by page. Do not do one massive redesign.
