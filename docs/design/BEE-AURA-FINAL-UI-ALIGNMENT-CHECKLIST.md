# Bee-Aura Final UI Alignment Checklist

## Source of truth pages

Use these as the accepted system style:
- Activity Log
- Reviews
- Follow-Ups

## Global rules

- Dark premium operating system.
- Do not make any page its own visual experiment.
- Do not use neon or cartoon status colours.
- Use gold only for primary commercial or Bee-Aura actions.
- Use blue for AI/system/diagnostics.
- Use green for success/recovered/completed.
- Use amber for warning/at-risk/pending.
- Use red for errors/failed/critical.
- Owner profile should match the accepted Activity Log / Reviews pill style.
- Primary action buttons should match the accepted gold button style.
- Search/select controls should match the accepted dark command bar style.
- Every visible control must do something visible in the demo.
