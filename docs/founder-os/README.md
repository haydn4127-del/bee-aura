# Bee-Aura Founder OS

This folder contains the operating documents for Bee-Aura AI / Lead Recovery OS.

The purpose of these documents is to stop the project becoming messy, unsafe, or dependent on memory.

Core rule:

ChatGPT controls the workflow.
The founder controls the gates.
Evidence unlocks progress.

Current first documents:

1. `01-core-document-set.md`
   - Defines the core Bee-Aura Founder OS document library.

2. `02-master-operating-rules.md`
   - Defines the master rules for ChatGPT, coding, governance, demo safety, approvals, commits, compliance and founder control.

These documents should be used before coding, deployment, sales, pilot planning or live product work.
